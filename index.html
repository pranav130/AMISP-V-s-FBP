📖 Methodology and Definitions

How each figure is built from the comparison workbook.

Sources

    Status report columns

    • 2 Feeder Bay Portal feeders · 3 AMISP MDM meters
    • 4 / 5 the same, excluding S/S, spare and incomer feeders (type Others)
    • 6 = 8 + 10 + 11 feeders whose division, substation and feeder match · 7 = 6 ÷ 5
    • 8 meter number and MF also match · 9 = 8 ÷ 5
    • 12 division mismatch · 13 = 5 − 6 − 12

    Direct vs manual matching

    • Direct: portal and AMISP substation names agree as written.
    • Direct + manual: also counts substations matched after normalizing 33/11 kV, S/S, dots, hyphens and spaces, or via the SS manual mapping sheet.

    AMISP feeder master

    • Feeder name: name if it contains "_", else code if it contains "_", else code when name is blank, else name. Polaris uses Omninet columns first.
    • TYPE: SPARE → Spare; INCOMER/INCOMING → Inc; names with "+" → Others; SUBSTATION / SUB STATION → SS; else Others.

    Monthly update workflow

    1. Run update_amisp_master.py on the new AMISP reports folder.
    2. Open the workbook, press Ctrl+Alt+F9, refresh Sheet1, update the status sheet, and save.
    3. Run build_dashboard_data.py to rebuild data.js, then push.

    📖 Methodology & Data Notes

    Matching Basis

    • Direct Matching: Portal and AMISP substation names match verbatim.
    • Direct + Manual Matching: Includes substations normalized by stripping 33/11 kV, S/S, punctuation/spaces, plus verified entries from SS manual mapping.

    Status Sheet Columns

    • Col 2 / 3: Total Feeder Bay Portal (FBP) vs AMISP MDM feeders.
    • Col 4 / 5: Feeders of type Others (excluding Substation SS, Spare, and Incomer feeders).
    • Col 6 / 7: Division, Substation & Feeder matched (and % of Col 5).
    • Col 8 / 9: Meter No. & Multiplying Factor (MF) also matched (and % of Col 5).
    • Col 10 / 11 / 12: MF mismatch, Meter No mismatch, and Division mismatch counts.
    • Col 13: Remaining unmatched feeders (Col 5 - Col 6 - Col 12).

    Data Scope

    Summary cards and overview charts cover the 4 non-KESCO Discoms (PVVNL, DVVNL, MVVNL, PuVVNL). KESCO is included in the Status Report table as entered in the workbook.
