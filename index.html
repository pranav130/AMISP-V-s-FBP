    Status report columns

    • 2 Feeder Bay Portal feeders · 3 AMISP MDM meters
    • 4 / 5 the same, excluding S/S, spare and incomer feeders (type Others)
    • 6 = 8 + 10 + 11 feeders whose division, substation and feeder match · 7 = 6 ÷ 5
    • 8 meter number and MF also match · 9 = 8 ÷ 5
    • 12 division mismatch · 13 = 5 − 6 − 12

    Direct vs manual matching

    • Direct: portal and AMISP substation names agree as written.
    • Direct + manual: also counts substations matched after removing 33/11 kV, S/S, dots, hyphens and spaces, or through the SS manual mapping sheet.

    AMISP feeder master

    • Feeder name: the name if it contains "_", else the code if it contains "_", else the code when the name is blank, else the name. Polaris uses Omninet columns first.
    • TYPE: SPARE → Spare; INCOMER/INCOMING → Inc; names with "+" → Others; SUBSTATION / SUB STATION → SS; else Others.

    Monthly update

    1. Run update_amisp_master.py on the new AMISP reports folder.
    2. Open the workbook, press Ctrl+Alt+F9, refresh Sheet1, update the status sheet, save.
    3. Run build_dashboard_data.py to rebuild data.js, then push.
